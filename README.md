# AlphaBlend — Part B: Funds, Sentiment & App

FINS3645 FinTech Project 2026 — Part B (Stations 3-4). Student: z5589978.

AlphaBlend is a prototype investment app offering systematically managed multi-asset
funds with news-sentiment analytics. Part A (data foundation) is in
`../z5589978_projectA`. This folder is the complete Part B deliverable.

## What was built

- **12 funds** across three asset families (equity-only, crypto-only, combined
  equity+crypto) and four optimisation methods (equal-weight, min-variance,
  max-Sharpe, risk parity), each with a walk-forward out-of-sample backtest.
- **VADER sentiment index** with an extended finance lexicon (~80 domain terms)
  scoring news headlines into a lagged sector-level sentiment signal.
- **Sentiment fusion** tilting equity fund weights by sector sentiment; before/after
  comparison reported.
- **Streamlit app** (`streamlit_app.py`) supporting the investor journey: compare
  funds, read each fund's fact sheet, set an allocation, view sentiment analytics.

## Key design decisions

- **Estimation window**: 252 trading days (1 calendar year of equity data).
- **Rebalance frequency**: first trading day of each calendar month.
- **First live date**: ~2021-01-04 (252 days into a 2020-start panel).
- **Risk-free rate**: 0 (stated assumption; no treasury proxy used).
- **Annualisation**: √252 for all fund return series (all on equity trading calendar).
- **Sentiment lag**: sector index shifted +1 trading day; day-t weights use day t-1 signal.
- **No-headline days**: carry-forward (ffill) then leading NaN → 0 (neutral).
- **Extended VADER lexicon**: ~80 finance-domain terms patched into VADER after init.
